# Laptop setup

Category: IT Support

Fictional Northstar demonstration content. Not a real company policy.

## Initial setup

IT Support provides an enrolled laptop with disk encryption and endpoint protection enabled. Sign in with your individual company account and install operating system updates before storing work files. Confirm that automatic screen lock activates after five minutes.

## Developer tools

Engineers install Git, an approved editor, and the team runtime versions from the software catalog. Container tooling requires the standard developer configuration. Ask IT Support before installing software outside the approved catalog.

## Hardware problems

Report laptop hardware problems through IT Support with the asset tag and a description of the fault. Do not open the device or arrange a third-party repair yourself. IT Support decides whether to repair or replace the device.
