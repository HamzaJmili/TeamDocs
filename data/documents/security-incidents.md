# Report a security incident

Category: Security

Fictional Northstar demonstration content. Not a real company policy.

## Report immediately

To report a security incident, open an urgent Security Desk ticket and notify the security on-call through the internal incident channel. Report suspected credential leaks, lost devices, suspicious access, or exposed customer data immediately. Do not wait for proof before reporting.

## What to include

Include the discovery time in UTC, affected systems, a brief description, and links to relevant logs in the security incident ticket. Never paste passwords, API keys, or customer records into a ticket. Preserve evidence and avoid deleting files or resetting systems unless instructed by the security responder.

## After reporting

The security responder acknowledges urgent incidents within 30 minutes during staffed hours. Outside staffed hours, use the emergency phone number listed in the internal staff directory. This demonstration document intentionally does not contain a real phone number.
