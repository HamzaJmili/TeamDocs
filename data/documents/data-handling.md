# Data handling principles

Category: Security

Fictional Northstar demonstration content. Not a real company policy.

## Classification

Northstar classifies information as Public, Internal, or Restricted. Public information is approved for external sharing. Internal information stays inside the company. Restricted information includes credentials and identifiable customer records, and requires explicitly approved access.

## Development data

Use synthetic data in development and staging. Do not copy production customer records into notebooks, test fixtures, or public repositories. Ask Security Desk for an approved workflow when a task genuinely requires restricted data.

## External AI tools

Do not upload Internal or Restricted company information to external AI tools without explicit security approval. This TeamDocs demonstration contains fictional public documents only; enabling its live mode sends retrieved passages and questions to the model provider.
