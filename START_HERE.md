# Start here

TeamDocs is ready to run as a local demo and prepared for GitHub and Render.

## What you have

- A complete application with a custom responsive interface.
- Twenty fictional company documents, with real source-linked search.
- Optional semantic retrieval and AI-generated answers once you add your own key.
- Tests, a 50-question benchmark and honest evaluation reports.
- A Sphinx handbook, an architecture illustration and a screenshot for GitHub.
- A Render blueprint and GitHub Actions workflow.

## Your next three steps

1. Follow the **Quick start** in [README.md](README.md). The no-key demo works first.
2. Read [the interview guide](docs/interview.md), trace one question through the code, and complete a few exercises.
3. Follow [the publishing guide](docs/deployment.md) to push to your GitHub account and deploy on Render.

The rendered handbook is in `docs/_build/html/index.html` in the delivered folder. Once you start the app, visit `/guide/` for the complete searchable documentation.

Live API calls, a public GitHub push and an actual Render deployment have not been performed. Add credentials only through `.env` locally or Render's secret settings. A successful local demo does not establish real-model answer quality.

This was built with AI assistance. Review and extend it so you can explain your decisions and contribution accurately in interviews.
